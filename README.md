# MANU YALA SAFARI TOURS - Premium Website

Official website for **Manu Yala Safari Tours**, a local safari tour operator based in Tissamaharama, Sri Lanka, offering wildlife safari expeditions in Yala National Park.

- **Typography**: Playfair Display (Editorial Serif Headings) & Plus Jakarta Sans (Clean Modern Body)
